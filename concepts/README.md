# Landing page concepts

Three directions for blacktilde.com. Open the `.html` files in a browser to try them.
Each page has a `projects` array at the bottom of the file: add a new subdomain there.

- **A: Terminal** (`a-terminal.html`): monospace, a `~` home directory, projects shown as `ls -l` output.
- **B: Editorial** (`b-editorial.html`): warm off-white, large serif wordmark, numbered index. Switches to dark mode automatically.
- **C: Cards** (`c-cards.html`): dark, subtle grid, project cards with live/beta/soon badges.
